## 动因

旧“支持列表”把静态候选、mise 安装记录和包管理器渠道混在一起，
容易把目录收录误作可安装证明，也与本机实例页形成两个主入口。
P14 扩工具前，先固定工具定义、来源覆盖及操作入口的边界，防止 Node 的支持范围被直接套到其他工具或平台。

## 落地

[后端目录](../src-tauri/src/tool_catalog/mod.rs) 是纯数据模块，新增只读 `tool_catalog` IPC。
它返回当前编译目标的平台，不读取用户环境、磁盘安装或配置，不运行命令、不生成计划，也不创建 journal。
[三平台契约样本](../fixtures/tool-catalog/contract-v1.json) 同时供 Rust 与 TypeScript 校验。

### 首批目录与能力账本

目录首批登记 Node.js、Python、Java、Go、Rust、Git、uv 七种工具，复用既有 `ToolDefinition` 和 `ProviderPackage`。
保留规范身份、显式别名、命令名、分类、说明及官方文档链接。
命令名用于搜索，不自动等同工具身份：`python3`、`javac` 能找到所属目录项，
但不作为来源身份归一化规则；Cargo、rustup、PyPy、`node@22` 不会被名称子串混为其他工具。
未知名称仍保持未知。

官方链接在本轮核对：[Node.js](https://nodejs.org/en)、[Python](https://www.python.org/)、
[Java](https://dev.java/)、[Go](https://go.dev/)、[Rust](https://rust-lang.org/)、
[Git](https://git-scm.com/)、[uv](https://docs.astral.sh/uv/)。
它们用于产品说明和手动参考，不把官网版本列表当成应用安装渠道的版本承诺。

每个工具按 provider 展示来源读取、安装计划、卸载计划、绑定计划，以及独立的项目核对状态。
状态为“入口已接入 / 尚未接入 / 当前不支持”，每项附原因。
**入口已接入不等于安装器存在、包可下载、目标归属已确认或获准执行。**
具体实例的版本、平台、归属、影响与执行权限继续由已有清单及操作计划核对。

| 工具 / 平台 | 本轮统一入口范围 |
| --- | --- |
| Node / macOS | mise、Homebrew、nvm、PATH 来源入口；mise/Homebrew 安装和卸载计划入口；mise/Homebrew/nvm 绑定入口；P13 项目核对。原有目标门禁和实机验收边界保持 |
| Node / Windows、Linux | 明确显示当前平台不支持统一流程，不继承 macOS 包身份或入口能力 |
| Python、Java、Go、Rust、Git、uv / 三平台 | 已登记工具定义；统一来源、计划及项目核对尚未接入，安装状态保持未知。兼容入口仍可按其既有范围使用 |

nvm 不获得安装或卸载计划；PATH 文件观测不变成可卸载、可绑定安装。
目录仅登记已确认的包身份示例，不列可用版本；没有新适配器时不猜测其他工具的原生包映射。

### 目录、机器证据与旧入口

[前端 API](../src/api/toolCatalog.ts) 拒绝未来格式、空目录、重复身份/冲突别名、
缺失能力说明、跨平台包和不安全的文档链接；读取失败不降级成可操作空清单。
[实例投影](../src/lib/catalogEvidence.ts) 直接使用 Node 详情同一份 inventory 状态，不发第二份扫描。

只有自身工具、provider、平台的覆盖能支持当前结果。
有新鲜目录记录显示“已观察到实例”，健康、归属和操作能力仍在详情中核对。
PATH 观测、旧记录、读取失败及部分来源不能证明安装存在或缺失；
只有已接入来源全部完整且没有目录记录，才显示“当前来源未观察到安装”，不声称系统绝对没有该工具。
没有接入的工具，即使收到同名额外记录，也不借 Node 的覆盖声称已安装。

[目录面板](../src/components/ToolCatalogPanel.tsx) 支持名称/别名/命令搜索和实例证据筛选，
各来源能力可用键盘展开。相同的原因在每个来源只显示一次。
目录刷新独立于机器扫描；失败保留旧目录并停用目录动作，隐藏期间的迟到回复不能污染新会话。
Node 动作定位既有清单并移动焦点，从那里使用原有计划；本工作包没有新增执行器或业务写 API。

主导航收敛为系统概览、本机工具、项目配置、服务与缓存、设置五项。
原 `software` 导航意图仍兼容，转入本机工具页的“更多工具与兼容渠道”；
“工具与来源”页签容纳运行时与 CLI，环境变量、预设和快照仍可访问。
旧 [SoftwareView](../src/components/SoftwareView.tsx) 第一次显式展开才挂载，收起后保留搜索、弹窗及任务会话，
非激活时停止其安装状态读取。它仍属于兼容流程，不把旧命令结果升级成统一计划的验证证据。
旧渠道静态候选 [catalog.ts](../src/data/catalog.ts) 也已注明兼容数据的身份。
P16 再逐项移除已完全替换的旧写入口；本轮没有删除现有跨平台能力。
