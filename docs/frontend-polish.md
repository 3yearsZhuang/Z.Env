# P10 / 39 — 前端工作流优化

日期：2026-10-13。本轮为尚未发布的前端改动。

## 动因

工作台框架与概览已有统一样式，其余页面仍存在扫描反馈缺失、项目列表截断、
渠道按钮依赖鼠标、读取失败被隐藏等问题。次要页面也随概览一起进入主入口代码。

## 落地

- 项目页按发现、编辑、预设组织；支持完整分页与名称/路径搜索，读取后定位编辑区，
  明确保存目标和未保存状态。读取、保存、绑定期间阻止重复提交；读取失败保留草稿并解除旧保存目标。
- 支持列表将版本管理、安装和复制拆为独立按钮，支持键盘操作、类型筛选、多关键词和包 ID 搜索。
  区分检测中、未知和已安装状态，提供失败重试与剪贴板反馈；安装仍使用后端规范包 ID。
- 服务与缓存分别管理加载、刷新、失败和重试，刷新时保留原数据；缓存确认弹窗展示占用、路径与官方命令，
  默认聚焦取消，操作期间禁止重复提交，关闭后恢复焦点。
- 全局任务面板折叠日志、即时显示取消中状态，轮询失败说明结果来自上次读取；最终状态以后台返回为准。
- 概览之外的页面按需加载；已访问的环境、软件和项目页保留挂载。切页回到顶部，窄窗导航只在跨越断点时调整。

## 验证记录

  `npm run build`（TypeScript + Vite）及 `git diff --check` 通过。
- 前端行为测试覆盖项目扫描重试、完整搜索/分页、保存互斥、读取失败保留草稿，
  软件键盘复制、规范 ID 安装、失败重试，以及服务/缓存确认和任务取消。
- 浏览器检查使用模拟 Tauri 数据，覆盖六个页面在 1000、780、390 像素宽度的布局，
  未见横向溢出或未捕获页面异常；检查深色主题、CodeMirror 编辑、切页保留草稿、
  窄窗导航、清理确认的取消和任务取消中状态。

## 后续：本机工具页信息架构再简化（2026-11-05）

### 动因

上一轮把「安装实例 / 全局变量 / 预设与快照」分成三块后，运行时区块里仍留着三只「盲盒」折叠区：
`工具能力台账`、`更多工具与兼容渠道`、`其他运行时与管理操作`；而承诺「装好 ≠ 生效」的环境健康巡检
恰恰被埋在最后一只盲盒里。切换卡的副标题又是来源清单（`mise / nvm / Homebrew`），在知道结果前先给出实现细节。

### 落地

- **环境健康上移为一等区块**：独立成「环境健康巡检 · 装好不等于生效」，紧跟实例清单，展开才巡检（不在页面加载时空跑）。
- **旧版入口合并**：`其他运行时与管理操作` 与 `更多工具与兼容渠道` 合成一个折叠区「其他工具与旧版渠道（N 个运行时）」，
  内部用二级标题分成「其他运行时与版本管理」「系统软件与兼容渠道」；兼容渠道仍在首次展开后常驻，收起不丢会话。
- **切换卡只说状态**：副标题改为「N 个安装实例 / 未发现安装实例 / 读取中… / 读取失败 / 点击查看实例」，
  来源清单交给下方清单面板。
- **反馈可见**：旧折叠区的错误与成功提示移到折叠区顶部；「本机已装 N 个运行时」横幅删除，
  环境变量冲突改为「全局变量」标签上的计数徽标。
- **文案与命名**：页头说明收敛为一句；第三个区块更名「预设与快照」（该区块同时含整机快照，旧名「可复用预设」不覆盖）。
- **视觉一致**：三个折叠区统一为同族卡片，等距对齐。

### 验证记录

- `npm test`：42 个文件 287 项（新增 4 项：切换卡状态文案、健康区块展开才巡检、旧版入口合并结构、冲突计数徽标替代横幅）；
  `npm run lint`、`npm run format:check`、`npm run build`、`npm run check:docs` 通过。
- 用 vite dev server + 注入的 Tauri IPC 桩在 headless Chromium 渲染真实页面：1280/760 宽无横向溢出，
  三个折叠区为同族卡片；标签页为「安装实例 / 全局变量 / 预设与快照」，折叠区标题按上述结构渲染。
- 未覆盖：真实 Tauri 窗口的视觉复核（当次机器锁屏），以及数据齐全时的清单渲染（桩只覆盖部分命令）。
