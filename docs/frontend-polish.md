# P10 / 39 — 前端工作流优化

日期：2026-10-13。本轮为尚未发布的前端改动。

## 动因

工作台框架与概览已有统一样式，其余页面仍存在扫描反馈缺失、项目列表截断、
渠道按钮依赖鼠标、读取失败被隐藏等问题。次要页面也随概览一起进入主入口代码。

## 落地

- 项目页按发现、编辑、预设组织；支持完整分页与名称/路径搜索，读取后定位编辑区，
  明确保存目标和未保存状态。读取、保存、绑定期间阻止重复提交；读取失败保留草稿并解除旧保存目标。
- 支持列表将版本管理、安装和复制拆为独立按钮，支持键盘操作、类型筛选、多关键词和包 ID 搜索。
  区分检测中、未知和已安装状态，提供失败重试与剪贴板反馈；安装仍使用后端规范包 ID。
- 服务与缓存分别管理加载、刷新、失败和重试，刷新时保留原数据；缓存确认弹窗展示占用、路径与官方命令，
  默认聚焦取消，操作期间禁止重复提交，关闭后恢复焦点。
- 全局任务面板折叠日志、即时显示取消中状态，轮询失败说明结果来自上次读取；最终状态以后台返回为准。
- 概览之外的页面按需加载；已访问的环境、软件和项目页保留挂载。切页回到顶部，窄窗导航只在跨越断点时调整。

## 验证记录

- `npm test`：11 个测试文件、67 项测试通过；`npm run lint`、`npm run format:check`、
  `npm run build`（TypeScript + Vite）及 `git diff --check` 通过。
- 前端行为测试覆盖项目扫描重试、完整搜索/分页、保存互斥、读取失败保留草稿，
  软件键盘复制、规范 ID 安装、失败重试，以及服务/缓存确认和任务取消。
- 浏览器检查使用模拟 Tauri 数据，覆盖六个页面在 1000、780、390 像素宽度的布局，
  未见横向溢出或未捕获页面异常；检查深色主题、CodeMirror 编辑、切页保留草稿、
  窄窗导航、清理确认的取消和任务取消中状态。
- 主入口 JavaScript 从本轮开始时约 384 KB 降至约 236 KB（未压缩，约减少 39%）。
  CodeMirror 仍为独立异步资源；此数字不代表总下载量或桌面启动耗时。
- 本轮未执行真实软件安装、服务启停或缓存清理，也未替代三平台桌面实机验收。
